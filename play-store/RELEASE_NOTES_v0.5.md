# Pop Parade V0.5

Open Kids Mode to choose Colors, Alphabet, Fruits, or Animals. Each learning set has three shuffled rounds. Every item is the correct target once per round, and an incorrect answer repeats the current prompt. Completed sets can be replayed.

- Alphabet covers all 26 English letters and shows uppercase and lowercase together.
- Fruits covers 52 names. Fruits with a matching emoji have a picture alongside their name.
- Animals covers 52 names with animal emoji.
- Players can hear each prompt again when spoken instructions are enabled.
- The Challenge arena previously in slot 29 is now Starlight Sprint. Existing clears, scores, and unlocks remain associated with the same levels.

Android application version: `0.5`, versionCode `5`. GitHub Actions builds a debug APK and an R8-optimized unsigned AAB. The AAB requires the existing registered upload key before Google Play submission.
