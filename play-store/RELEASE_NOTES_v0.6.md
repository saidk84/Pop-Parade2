# pop balloons: Learn & fun V0.6

Kids Mode includes Numbers 0–10. Each number is the correct target three times in a 33-turn set. Balloons show the digit and English word, prompts can be replayed, and completed sets are saved locally.

The game uses the new name on the web and in Android. Android retains package `com.popparade.app` and uses version name `0.6` and version code `7`.
